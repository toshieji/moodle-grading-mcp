## 1. 採点の全体構造

各節目を **10点満点** で採点する。

```
節目得点 = 内部修正点（最大6） + 外部追加点（最大4）
　ただし 事実誤認あり → その節目は 0点
　かつ  機密配慮チェックに×が1件でもある → AI使用ログ全体が 0点

課題のAI監修プロセス評価 = 全節目の節目得点の平均
最終評価 = AI監修プロセス評価 ＋ 課題ごとの加点・減点（⚠️§15で別途設計）
　　　　　　配点倍率は現行配分を踏襲（⚠️§16）
```

## 2. 内部修正の評価（最大6点）

AI出力の**内側で完結する**操作。各項目は独立加点（合算可）。

| 配点 | 内容 | 判定の目安（二値で判定：満たせば加点、満たさなければ0） |
| :--: | :-- | :-- |
| 1点 | フォーマット整形・読みやすさ向上（AIらしい癖を抜く、直した箇所を明示） | **修正箇所が太字/赤字/差分等で具体的に明示されている場合のみ加点**。「整形した」と申告するだけで明示が無ければ0点 |
| 2点 | AIの誤解・矛盾を発見し修正／削除 | **どの誤解・矛盾を／なぜ誤りと判断したかの両方**が書かれている場合のみ加点。片方のみは0点 |
| 3点 | AIの推論を発展させた論理展開（AI出力内で完結） | **AIの前提から一歩進んだ独自の論理が具体的に**示されている場合のみ加点。言い換え・要約に留まれば0点 |

> 文章修正をしていない場合は1点が取れないだけ。他の修正があれば加点される。
> **評価者間のブレ抑制**：各行は上記の明示条件を満たすか否かの二値で判定する（程度評価をしない）。判断に迷う場合は「明示が不足」とみなし加点しない。境界例は§8サンプル集に追加していく。

## 3. 外部追加の評価（最大4点）

AIが知らない情報を**持ち込む**行為（「修正」ではなく「追加」）。

| 配点 | 内容 | 根拠欄(H)に必須の記載 |
| :--: | :-- | :-- |
| 2点 | 記述データ（社内資料・既存統計・**WACA提供データ**・公開一次資料等）に基づく独自意見の追加 | 出所（例：2024年度自社GA4データ／WACAオウンドメディア分析／公開統計の出典） |
| 2点 | ヒアリング・実データ分析（顧客ヒアリング・自社CV分析・**WACAデータの実分析**等）に基づく独自意見の追加 | 実施日・対象（例：A社人事部長へ30分ヒアリング 2026/4/20／WACAデータ◯◯を集計） |

> **プランB（自社データ無し）の扱い**：協会が提供する **WACAデータ**（協会オウンドメディア／会員データ等）や**公開一次資料**を自分で分析・参照して導いた独自の数値・知見は、出所を明記すれば上表の外部追加点の対象とする（プランAの自社データ・ヒアリングと同等）。これによりプランA／Bの得点上限の差を解消する。
>
> **対象外（外部点が付かないもの）**：出所が**一次でない伝聞のみ**（「業界では◯割と聞く」等、検証可能な出典が無い）の追加は、外部追加点の対象外。内部修正点（論理材料）としては評価しうる。

## 4. ゼロ点条件

| 条件 | 範囲 | 判定 |
| :-- | :-- | :-- |
| 事実誤認（一般業界知識・協会事業内容の明白な誤り） | その節目のみ0点 | 例：「ウェブ解析士は中小企業しか受講しない」、市場規模の誤り |
| 機密配慮チェックに×が1件 | **AI使用ログ全体0点** | §5のチェックリスト参照。申告と実態の不整合・第三者情報の無断使用も対象 |

## 5. 機密配慮チェックリスト（全節目共通）

各行を ◯（問題なし）／×（違反）で判定する。**1つでも×があれば AI使用ログ全体0点**。

| # | チェック項目 | ◯の条件 | ×（全体0点）の条件 |
| :--: | :-- | :-- | :-- |
| 1 | 自社の固有の顧客名・PII | 含めていない／含む場合は匿名化（`<company_A>` 等）し理由を記述 | 実在の顧客名・PII を匿名化せず投入 |
| 2 | 自社の具体的な売上数値等の機密情報 | 含めていない／匿名化・丸め＋理由を記述 | 実機密数値を無断で投入 |
| 3 | **第三者（自社顧客以外）の固有名・固有の数値** | **当該企業の許諾／公開合意を確認している**（許諾済みなら固有名のまま可）／または匿名化して投入 | **許諾を確認せず第三者の固有名・固有数値を投入（無断使用）** |
| 4 | 判断理由・許諾確認の記録 | 含めた場合に、匿名化の有無・許諾確認の事実を記述した | 含めたのに理由・確認の記録が無い |

> **第三者情報の核心（C1確定方針）**：第三者企業の固有名・伝聞数値も、**該当企業が公開に合意していれば使用可（◯）**。採点では「受講生が**許諾／合意を確認したか**」を見る。許諾の記録があれば◯、無断使用なら×（全体0点）。匿名化して投入した場合も◯。
>
> 講師はプロンプト本文を確認し、申告と実態の不整合（含めていないと申告しつつ固有名詞を入れている等）も×として判定する。

## 6. 講師の採点手順（§5.2.6）

1. スプレッドシートのダッシュボード（自動集計）で修正種類分布・機密配慮チェックを確認
2. 機密配慮に×があれば即0点判定（以降の採点不要）
3. 各節目の「受講生による修正・意思決定」欄を通読し、自己申告された修正種類との整合を確認
4. 事実誤認の有無を確認（一般業界知識・協会事業内容に関する誤認のみ）
5. 各節目を内部最大6点・外部最大4点で採点し、平均値を算出
6. 課題ごとの加点・減点項目を加味して最終評価（⚠️§15）
- 採点工数の目安：1人あたり10〜15分（節目10前後の場合）

## 7. 口頭試験との連動（§5.2.7）

口頭試験「AI活用」カテゴリで、受講生本人のAI使用ログから**1問必出**。
- 例：「第N節目で『ヒアリングに基づく追加』とあるが、具体的にどんなヒアリングか？」
- 例：「この修正は『AIの推論を発展させた』とあるが、発展のポイントは何か？」
- 虚偽申告の疑いがある場合、当該ログを再評価し減点または不合格判定の対象とする

## 8. 採点サンプル集（⚠️ドラフト・要委員会レビュー）

v2.4「受講生向けサンプル集」（高評価／中評価／事実誤認／過剰外部追加で根拠不十分）の**枠**。
以下は構造を示すドラフト例であり、確定は江尻氏・委員会判断（R4）。

| 型 | 内部点 | 外部点 | 節目得点 | 着眼点（何が評価/減点されたか） |
| :-- | :--: | :--: | :--: | :-- |
| 高評価例 | 6 | 4 | 10 | 整形明示＋矛盾修正＋論理発展。自社GA4と顧客ヒアリング両方で独自意見を追加し出所明記 |
| 中評価例 | 3 | 2 | 5 | 矛盾修正のみ（整形・論理発展なし）。外部は記述データ1件、ヒアリングなし |
| 事実誤認例 | — | — | 0 | 論理展開は良いが業界知識に明白な誤り→当該節目0点 |
| 過剰外部追加・根拠不十分例 | 2 | 0 | 2 | 「独自意見」を多数追加するが根拠欄(H)に出所記載なし→外部点つかず |

> 確定時は各型の**完全な記入例（実際の節目記述）**を3〜5パターン用意し、受講生に事前公開する。
